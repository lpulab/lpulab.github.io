# 探索心靈與大腦中的語言

{:.center}
歡迎來到國立臺灣師範大學國文學系的語言處理及使用實驗室網站！

{:.center}
我們致力於理解語言的使用方式及其在大腦中的表徵。我們運用語料庫探勘、行為實驗及神經影像技術等多種量化方法來支持理論分析。我們對於整體的「多樣性」特別感興趣：包括語言的多樣性、個體的多樣性（如不同年齡層、不同社經背景的人群等），以及研究主題的多樣性。

{:.center}
**目前研究的語言：** 英語、排灣語、他加祿語、臺灣華語、太魯閣語
{:.center}
